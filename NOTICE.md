# Scope of the licence

This licence covers the code in this repository and the annotation files in
protocol/frozen/, which are measurements produced by the authors of this
repository: bounding box coordinates, near duplicate lists, flagged label pairs
and merge decisions.

It does NOT cover the CURE pill image collection. No image from that collection,
and no image derived from it, is distributed here. Obtain the collection from its
original authors at https://github.com/suiyiling/Few-shot-pill-recognition and
respect whatever terms they state.
